# Cells 医养协同系统

面向养老机构的医养跨专业协同 Web MVP。系统围绕 Elder Cells 长期状态模型，演示异常事件识别、多角色评估、依赖链路、冲突检测、统一照护方案、人工确认、任务闭环和决策管理。

## 本地运行

```bash
npm install
npm run dev
```

访问：

```txt
http://127.0.0.1:5173/
```

## 构建

```bash
npm run build
```

构建产物输出到 `dist/`。

## 部署配置

适合部署到 Vercel、Netlify 或其他静态站平台。

```txt
Build command: npm run build
Output directory: dist
```
